# Employee Management System 👨‍💼

A full-stack Employee Management System built using the MERN stack for **Project 3** of **Task 3** in the **Syntecxhub Web Development Internship**[cite: 38, 43]. This application allows administrators to efficiently manage company personnel with full CRUD operations and proper form validation[cite: 43].

## 🚀 Features
* **CRUD Operations:** Easily add, update, delete, and list employees[cite: 43].
* **MERN Architecture:** Clean React frontend connected to a Node.js and Express backend[cite: 43].
* **Database Storage:** Securely stores employee information (such as name, role, salary, etc.) in MongoDB[cite: 43].
* **Validation & Design:** Built with proper form validation and a responsive user interface design[cite: 43].

## 🛠️ Tech Stack
* **Frontend:** React.js, HTML5, CSS3[cite: 43]
* **Backend:** Node.js, Express.js[cite: 43]
* **Database:** MongoDB[cite: 43]
